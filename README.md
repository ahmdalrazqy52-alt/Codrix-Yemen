# Codrix Yemen

المصدر الكامل لموقع Codrix Yemen ولوحة الإدارة، مبني باستخدام React وTypeScript وVite وTailwind CSS وSupabase.

## ابدأ من هنا

- تعليمات التشغيل والنشر: `README_PRODUCTION.md`
- قائمة ما قبل الإطلاق: `DEPLOYMENT_CHECKLIST.md`
- ملاحظات الأمان: `SECURITY_NOTES.md`
- تقرير الفحص والإصلاحات: `FINAL_QA_REPORT_AR.md`

## متطلبات التشغيل

- Node.js 20 أو 22 LTS
- npm
- مشروع Supabase

انسخ `.env.example` إلى `.env` وأدخل بيانات مشروعك، ثم نفّذ `npm ci` و`npm run dev`.
